## Issues and Pull Requests

### Working on Issues

We use GitHub issues to track public bugs, when creating an issue, please give clear and sufficient instructions on how to reproduce the issue. 

For security related issues, do not create a public issue or comment, and instead report it to our [GitHub Advisory Page](https://github.com/asago-ai/asago-repo-template/security/advisories/new). For more details, please check the [SECURITY.md](/SECURITY.md) file.

### Submitting Pull Requests

When you are ready to contribute, follow these steps for your Pull Request:

* **Check existing PRs:** Search through open PRs to ensure your contribution isn't already being worked on.
* **Link your PR:** Reference the related GitHub issue in your PR description (e.g. `Closes issue #123`).
* **Respect the assignment:** Keep Pull Requests focused to the issue. Do not include unrelated changes in the same pull request.
* **Pass all checks:** If applicable, before submitting your PR, make sure to run tests locally and ensure they pass, follow the project coding conventions, and write detailed commit messages.

### Types of Contributions

There are multiple ways one can contribute to our project!

* **Report Issues:** Let us know about bugs, unexpected behaviors, or feature requests by opening an issue.
* **Code Contributions:** Fix bugs, add new features, or optimize performance.
* **Documentation:** Improve readability, fix typos, add examples, or write guides.
* **Speaking & Advocacy:** Share the project at meetups, write blog posts, or help others in the community.
