# Benign requests

Hand-written normal user requests per use case, written from `use_case.txt` only (the author did not see policies, attacks or rails). Each request is `plain` (clearly ordinary) or `borderline` (ordinary but close to a sensitive topic).

Used by `test --benign-requests examples/benign_requests` to measure false positives; see [docs/deploy-and-test.md](../../docs/deploy-and-test.md).
